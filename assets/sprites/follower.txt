; follower.txt
;
; A worker you have freed, walking behind you, seen from directly
; overhead. Two frames.
;
; Why a third people sprite exists at all: raised arms MEAN "I still
; need reaching", and leaving them up on somebody already walking
; behind you is a lie the player would act on. A worker is drawn from
; their state, so a follower dropped back to waiting goes back to
; arms up on the frame they are dropped -- and keeps its frame bit,
; because the bit says which foot is forward and not what they are.
;
; REDRAWN 2026-09-11 (issue #60): a disc, shoulders six wide, hands
; beside the hips and feet under. NOTHING IN IT TOUCHES COLUMN 0 OR 7
; IN EITHER FRAME, which is what has always told it from the player.
; The frames differ in rows 8-11 by twelve pixels -- hands swinging,
; feet swapping -- and it flips when the figure crosses a cell, which
; a follower does every time the tail carries it over one. B is A in
; the mirror.
;
; 36 pixels -- the lightest figure in the game, down from 44. That is
; a legibility cost and it is priced: a remembered wall cell is 8 to
; 28 pixels today and 8 to 34 once the outline gains its courses, so
; the follower still out-inks every wall cell it can stand beside. It
; never stands ON one -- collision refuses any position overlapping a
; solid cell -- and the head disc is the thing the eye finds. If a
; session loses a follower against a wall, the head grows a row
; before the walls lose their courses.
;
; Authored here and generated into prototype/spikes/bitmaps_gen.py
; and spectrum/src/bitmaps.asm by tools/bitmaps.py. Comments start
; with ';' rather than '#', which is what a row of eight set pixels
; starts with -- the first version of this format used '#' and
; silently ate the player's shoulders.
