; worker.txt
;
; A trapped worker, waiting, seen from the front. Two frames: calling,
; and the wave.
;
; REDRAWN 2026-09-12 (issue #72), IN ELEVATION, with the player and
; the follower and for the same reason -- see player.txt for the
; ruling. The same person as the follower -- the same head, neck,
; shoulders, legs and boots -- with the ARMS UP: two arm strips rising
; from the shoulders past the head to hands above it, which is what
; raised arms look like from the front and is the whole of the signal.
; It is the only figure with ink on the top row that is not the
; player's lamp, and where the lamp is four centred pixels the hands
; are two pairs either side of the lamp's middle two columns, so the
; two are never the same shape at the top where a glow finds them.
;
; The hands were moved in from the edge columns before this was built:
; the designer's mock put them at columns 0 and 7, and the contract
; check found that put the whole difference from the follower in the
; edge columns, which is the fault assertion 2 exists to refuse.
;
; THE WAVE PLAYS ON THE SHOUT. A waiting worker does not walk, so it
; has no stride; what it has is the call it already raises every few
; seconds. While its HELP is painted on the screen it is drawn on
; WORKER_W -- arms out from the shoulders, hands level with the head --
; and goes back to WORKER when the word clears. On the event, never on
; a counter and never on a random number: the cells are already dirty
; for the word, so the wave costs no redraw the shout was not paying
; for. This is the one-line lever the plan-view drawing named and did
; not pull; the user's ruling pulled it (row 6 of "Look and feel 2").
;
;   Do NOT give it a counter to make it look alive. It is waiting.
;
; Breathing was refused with the fly's own lesson: the tester measured
; a frame change of eight corner pixels and found it read as no
; animation at all, and a breath at 8x16 is two pixels of shoulder for
; a redraw of a figure that has not moved.
;
; A dropped follower goes back to WORKER on the frame it is dropped,
; because the drawing is chosen from the state and not remembered.
;
; 50 pixels calling, 44 waving. The wave keeps rows 4 onward.
;
; Authored here and generated into prototype/spikes/bitmaps_gen.py
; and spectrum/src/bitmaps.asm by tools/bitmaps.py, which also
; derives the one-pixel halo mask (issue #70). Comments start with
; ';' rather than '#', which is what a row of eight set pixels
; starts with -- the first version of this format used '#' and
; silently ate the player's shoulders.
