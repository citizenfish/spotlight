; lamp.txt
;
; The lamp family: one silhouette, three meanings, told apart by their
; middles -- EMPTY IS DARK, FILLED IS BURNING, A LENS IS BOLTED DOWN.
; Plus a fourth that is deliberately not an octagon at all.
;
; These replace a lamp drawn in elevation -- a handle, a dome and a
; beam spreading downward -- which was the only object in the game
; that disagreed with the camera, and the reason nobody noticed is
; that it was never drawn: there was no draw call for a dropped
; spotlight anywhere in the game, so the whole pick-up-and-swap
; economy had never once been on screen (issue #49).
;
; LAMP_OFF and LAMP_ON share a silhouette on purpose, which the
; legibility contract otherwise forbids of a pair of states that means
; something. The exemption is real rather than an oversight: a burning
; lamp sits inside the pool of light it is making, and that pool is a
; far larger cue than the eight bytes in the middle of it. It is the
; only state pair in the game with a second channel of its own. If a
; session ever reports a spare being mistaken for a burning one, this
; is the paragraph that gets reopened.
;
; Authored here and generated into prototype/spikes/bitmaps_gen.py
; and spectrum/src/bitmaps.asm by tools/bitmaps.py. Comments start
; with ';' rather than '#', which is what a row of eight set pixels
; starts with -- the first version of this format used '#' and
; silently ate the player's shoulders.
