; The player, seen from the front, standing on the plan-view floor.
; Three frames: a neutral stance and two strides.
;
; REDRAWN 2026-09-12 (issue #72), IN ELEVATION, on the user's own
; reversal of the user's own 2026-09-07 request. The figure was asked
; for from above, drawn to those words twice -- once as a front view
; foreshortened, once as a disc of head and shoulders with feet
; peeking out -- and both times the user played it and said it did
; not read. The designer's note "Why the figures read as clunky" put
; the cause in one word, projection: a plan-view person eight pixels
; wide is a token, a disc on a wider disc, and a walk drawn on it
; moves the hem and not the mass. Shown a front-view figure beside
; the plan-view one in the same played frame, the user chose the
; front view -- which is what Atic Atac, Sabre Wulf, Nightshade and
; Gauntlet all did: elevation figures walking across a floor seen
; from above, and nobody minded the mixed projection. The Cleg, the
; walls, the floor and the lamps stay in plan. The people stand up.
;
; ONE FACING, NO MIRROR. A front view is symmetric, so there is no
; left or right to draw, and the light is still what says which way
; you are looking. The no-facings argument of 2026-09-07 is untouched.
;
; What he is, top to bottom: the lamp on his helmet (rows 0-1, four
; pixels, centred, symmetric, exactly where it was); the helmet, a
; visor and a chin; shoulders at the full width of the box -- the kit
; -- which no other figure has; arms down the sides, hands at the
; hips; a belt; legs; boots. The last row is clear.
;
; THERE IS NO BAR UNDER HIS FEET. Since issue #49 he wore two marks,
; the lamp and a solid bar in the bottom two rows, because a plan-view
; figure had nothing else to tell him from a follower on lit floor.
; In elevation the helmet and the full-width kit do that in the middle
; columns where the eye is, and the legibility contract -- every frame
; of him against every frame of the other two -- passes without the
; bar and fails without the lamp. The bar's five-pixel clause is gone
; with it, not kept and skipped; assertion 4's five-pixel rule still
; governs marks meant as marks, which is now the lamp alone, exempt
; as it always was.
;
; THE WALK IS FOUR STEPS OVER THREE FRAMES: N A N B, advancing every
; FOUR PIXELS OF TRAVEL along either axis -- never per frame, never per
; cell. He moves a pixel a frame, so that is a new frame every four
; frames of walking, about 12Hz, which is a walk; the cell cadence
; before it was a 6Hz flip that read as a foot twitch under a sliding
; blob. A figure that stops holds its stride. The counter is
; `walk.Stride`, drawing state that nothing in the rules reads; the
; event log is byte-identical with it and without it.
;
; The strides move the arms and the legs and nothing above the
; shoulders: A swings one arm forward and scissors the legs one way,
; B is A in the mirror, so across a cycle the figure stays centred
; over its column and never leans. The boots in A and B reach the
; edges of the column (row 14, `##....##`); in N they are inboard.
;
; 68 pixels of ink in N and 65 in each stride, against 50/47/47 for a
; follower and 50/44 for a waiting worker. Fifteen of the sixteen
; rows are used; the port's twelve-row saving does not apply to these
; and is out of scope.
;
; Authored here and generated into prototype/spikes/bitmaps_gen.py
; and spectrum/src/bitmaps.asm by tools/bitmaps.py, which also
; derives the one-pixel halo mask (issue #70). Comments start with
; ';' rather than '#', which is what a row of eight set pixels
; starts with -- the first version of this format used '#' and
; silently ate the player's shoulders.
