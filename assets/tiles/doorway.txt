; doorway.txt
;
; The returns for a 'd' cell: short ticks continuing each wall the doorway
; touches into the opening. Floor in every mechanical respect -- walkable,
; stippled, remembered, and NOT solid -- and drawn like this so that a one-cell
; gap reads as a doorway rather than as a room that stops there.
;
; Same sixteen masks as the walls, read the other way round: a bit that is SET
; means there is a wall on that side, and a wall on that side is what a return
; continues. The jambs come free -- the wall cells either side of a gap already
; get their inward faces outlined by their own mask -- so a doorway is a pair
; of drawn jambs with returns between them, which is what a doorway looks like
; on a plan.
