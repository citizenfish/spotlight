; assets/levels/level3.txt -- Level 3, Rescue: the column.
;
; THIS FILE IS THE SOURCE and spikes/scene.py is a view of it (issue #107).
;
; Re-authored as **the column** in #146: straight down, and **no east-west
; doorway anywhere in the building**. By the time a player reaches Level 4's
; ring they will have met the east-west axis (Level 1), the corner (Level 2)
; and the north-south axis on its own (Level 3), separately, each with the rest
; of the game held still.
;
; **What this cost, said plainly.** Level 3 is `SCENE_LEVEL` and the sixteen
; baseline hashes were its; a column moves every one of them. The round
; re-baselines in #147, so the cost is paid once -- and the alternative was to
; keep Level 3 the row it was and let Level 2 carry the corner alone. A
; three-step teaching sequence is worth more than a building's provenance, and
; that provenance was spent already when #137 gave this level a third room.
;
; Format: `level:`, `name:` and `building:` once, with the budget -- `blood:`,
; `spray:`, `lives:`, `magnet:` seconds, `wake: on|off`, `fade:` 1 or 2, and
; `people:` the roster -- before the first `shape:` or `room:`; then `shape:`
; blocks, then `room:` blocks. A room carries `map:` (22 rows of 32) with
; `worker: x y blood` and `cleg: cx cy`; or `roll:` with `segments:`,
; `length:`, `pieces:`, `band:`, `away:`, `clegs:` and one `shell:` a shell it
; may be built from. Every room has `searchlight: radius repeat|vary` (with
; `pace:` beside it), `start: x y` in pixels and `at: col row` on the plan;
; `light: left top width height` and `door: side span-span room` as authored.
; Blank lines and `;` comments go anywhere.
;
; **`people:` is the building's and a rolled room does not author its own**
; (#143): one clock a person on one line, and the deal gives every room that is
; not a dead end somebody first, then the dead ends in a rolled order, then the
; rest, handing the shortest clock to the room nearest the way out.
;
; **The floor hue is not authored** (#145): it is `(col + row) & 1` of `at:`, so
; adjacent rooms never share one and every doorway crossed flips the colour.
;
; (`spotlight:` and `torch:` went with the torch, #119; `mount:` went in #137;
; `worker:` in a `roll:` room went in #143; `floor:` went in #145.)
